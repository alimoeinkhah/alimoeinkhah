# Ali Moeinkhah

## Geospatial AI & Earth Observation Specialist

**Remote Sensing · GIS · Machine Learning · Spatial Data Engineering**

I build end-to-end geospatial analytics solutions that transform satellite imagery, environmental data, and spatial databases into decision-ready insights.

My work combines Earth observation, machine learning, GIS, and interactive visualization to address real-world challenges in urban growth, land-cover change, natural-hazard assessment, environmental monitoring, and predictive analytics.

### Selected Impact

- Mapped Isfahan’s urban expansion from 1985 to 2024 and quantified **599.51 km² of built-up growth** using Landsat imagery, SVM, Random Forest, NDVI, NDBI, and post-classification change detection.
- Developed a GIS-based **landslide susceptibility and population-exposure workflow** with an interactive WebGIS for northern Sondrio, Italy.
- Built a **PostgreSQL/PostGIS air-quality monitoring platform** for Lombardy using Python, Flask, Dash, GeoPandas, and Plotly.
- Applied machine-learning methods to remote-sensing classification, environmental analysis, and predictive-maintenance workflows.
